GlazeBar + GlazeWM 0.1.0-preview.6 — Windows 11 x64 / ARM64

GlazeBar와 수정 GlazeWM 3.10.1-glazebar.1을 설치하는 커뮤니티 번들입니다.
PC에 맞는 설치 프로그램을 사용하고 실행 중인 GlazeWM과 GlazeBar를 종료하세요.
이전 커뮤니티 번들은 먼저 제거하고 사용자 설정 백업을 보관하세요.

설치 위치: %USERPROFILE%\.glzr\glazewm
백업 위치: %USERPROFILE%\.glzr\community-backups
기존 파일을 백업하며 다른 GlazeWM 버전을 임의로 교체하지 않습니다.
GlazeWM의 Visual C++ 런타임이 없으면 Microsoft에서 내려받아 서명을 확인하고
설치 화면을 표시합니다. 인터넷과 관리자 권한 확인이 필요할 수 있습니다.
로그인 시 자동 시작은 다음 화면에서 선택합니다.
설치 후 시작 메뉴의 GlazeBar + GlazeWM을 실행하세요.

이번 버전은 주석 색상이 본문 색상과 같아지는 문제를 수정합니다.
업데이트 후 현재 배경화면/테마를 다시 선택하고 VS Code에 적용하세요.
Wallhaven 탐색·보관함과 배치를 보존하는 최소화·복원도 포함됩니다.

제거 시 Windows 설정 > 앱에서 커뮤니티 번들을 제거하세요.
설치 전 파일을 복원하고 설치 후 수정한 파일은 별도 보관합니다.
백업·캐시, 공식 GlazeWM, 적용한 Windows 색상·배경화면은 유지합니다.

x64는 실제 Windows에서 검사합니다. ARM64는 교차 빌드 및 패키지 검사이며
이번 버전의 실제 ARM64 기기 실행은 검증하지 않았습니다.
새 Windows의 MSI/UAC 전체 설치 검증은 별도입니다. 게시자 코드 서명은 없습니다.
GlazeBar 및 설치 스크립트는 GPL-3.0-only이며 제삼자 라이선스를 유지합니다.
대응 소스와 고지는 설치 폴더의 bundle/source, bundle/licenses, setup-source에 있습니다.
날씨는 서울 기준이며 Open-Meteo 무료 API의 비상업용 조건이 적용됩니다.

English: This community bundle installs GlazeBar and modified GlazeWM.
Close both programs and uninstall an older community bundle before updating.
Keep configuration backups. After installation, reselect your wallpaper/theme and
apply it to VS Code to regenerate readable, distinct comment colors.
ARM64 is cross-built, without physical ARM64 execution validation for this version.
Corresponding source and licenses are included. See the repository for details:
https://github.com/lamininA1/GlazeBar
