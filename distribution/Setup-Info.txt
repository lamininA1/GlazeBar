GlazeBar + GlazeWM 통합 설치

이 설치 프로그램에는 다음 두 프로그램이 모두 들어 있습니다.
  • GlazeBar: Rust 네이티브 상태 표시줄과 빠른 설정·배경화면 도구
  • GlazeWM 3.10.1: 창 자동 배치와 작업공간 관리 프로그램 (공식 MSI)

계속하기 전에 실행 중인 GlazeWM과 GlazeBar를 종료하세요.
기존 설정과 덮어쓸 파일은 먼저 백업합니다. GlazeWM 3.10.1이 이미 있다면
그대로 사용합니다. 다른 버전을 임의로 교체하지 않습니다.
이전 커뮤니티 번들이 설치되어 있다면 먼저 제거하고 원래 설정을 복원하세요.

명령어를 직접 입력할 필요는 없습니다. 설치 마법사가 필요한 작업을 수행합니다.
GlazeWM 설치 과정에서 Windows 관리자 권한 확인이 나타날 수 있습니다.
GlazeWM에 필요한 Visual C++ 런타임이 없으면 Microsoft에서 직접 내려받아
서명을 확인한 다음 설치 및 라이선스 동의 화면을 표시합니다.
이 경우 인터넷이 필요합니다. GlazeBar 자체에는 별도 런타임이 필요 없습니다.

로그인 시 자동 시작 여부는 다음 화면에서 선택할 수 있습니다.
설치 후 시작 메뉴의 GlazeBar + GlazeWM을 실행하세요.
Win+F1을 누르면 단축키 안내를 볼 수 있습니다.

제거 및 복원
Windows 설정 > 앱 > GlazeBar + GlazeWM (community setup)에서 제거합니다.
먼저 두 프로그램을 종료하세요. 설치 전 설정을 복원하며, 설치 후 수정한 파일은
별도로 보관합니다. 백업과 사용자 캐시는 남겨둡니다.
GlazeWM 자체는 계속 사용할 수 있도록 남겨둡니다. 완전히 제거하려면
Windows 설정에서 GlazeWM도 따로 제거하세요.
직접 적용한 Windows 테마와 배경화면은 제거 시 초기화하지 않습니다.

라이선스와 소스
GlazeBar 자체 코드와 설치 스크립트: GPL-3.0-only.
GlazeWM: GNU GPL v3. 제삼자 구성 요소의 원래 라이선스는 유지합니다.
설치 폴더의 bundle/licenses, bundle/source, setup-source에서 고지와 소스를
확인할 수 있습니다. Inno Setup을 사용해 설치 프로그램을 만들었습니다.
GlazeWM 공식 배포판이 아닌 독립적인 커뮤니티 번들이며, 보증은 제공하지 않습니다.

현재 검증 범위
실제 Intel/AMD PC와 새 Windows 환경의 MSI/UAC 설치 검증은 남아 있습니다.
설치 EXE와 GlazeBar에는 게시자 코드 서명이 없습니다.
날씨의 기본 지역은 서울이며 Open-Meteo 무료 API의 비상업용 조건이 적용됩니다.
